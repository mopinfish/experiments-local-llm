# Phase 9-C Step 3: QLoRA FineTuning による地理的 POI 質問応答の品質改善実験

**実験日**: 2026-03-01
**実験ID**: PHASE9C_STEP3
**ブランチ**: `feature/phase9c-step3-qlora`
**結果ファイル**: `results/phase9c_step3_20260301_103931.json`

---

## 概要 (Abstract)

本実験は、地理的 POI 質問応答システムにおいて QLoRA FineTuning（FT）が回答品質に与える効果を、4 システム比較実験により定量的に分離測定した。ベースモデル Qwen3-32B に対し 59 件の高品質回答で QLoRA 学習を実施し、(A) RAG のみ、(B) FT + 改善プロンプト、(C) FT + RAG、(D) FT + オリジナルプロンプトの 4 構成を 130 テストケースで評価した。

**主要結果**: FT 単体の効果はほぼゼロ（D: 51.2 vs C0 ベースライン: 52.2 = -1.0pt）であり、スコア改善の支配的要因はプロンプト改善（B - D = +16.7pt）と RAG（A - D = +19.2pt）であった。FT + RAG の相乗効果は負（-0.9pt）で、C3 目標（composite 75+）は未達（69.5）となった。本結果は、59 件規模の少量データによる QLoRA が地理的知識の汎化獲得には不十分であること、およびプロンプトエンジニアリングと RAG が現時点で最も費用対効果の高い品質改善手法であることを実証した。一方、過学習分析において学習データ選定バイアスの存在が示唆され、FT 効果の正確な測定には実験設計上の考慮が必要であることも明らかになった。

## 1. 序論

### 1.1 研究背景

Phase 9-C では、地理的 POI 質問応答システムの回答品質を段階的に改善する 3 ステップ実験を実施してきた。Step 1（プロンプト改善）では composite_score を 52.2 → 67.1（+14.9pt）に改善し、Step 2（モデル変更 7B → 32B）でさらに 67.1 → 70.4（+3.3pt）に到達した。Step 3 では QLoRA FineTuning により 75+ を目指す。

先行研究において、LoRA/QLoRA による PEFT（Parameter-Efficient Fine-Tuning）は、少量のドメイン固有データでの LLM 適応に有効であることが報告されている。しかし、RAG システムとの組み合わせにおける効果の分離測定は十分に行われておらず、特に「FT が改善しているのか、それともプロンプト改善の効果を FT と誤認しているのか」という交絡因子の分離は重要な未解決課題であった。

### 1.2 研究目的

本実験の目的は以下の 3 点である：

1. **QLoRA FT の純粋効果の測定**: プロンプト改善・RAG の効果と分離して、FT 単体がもたらす品質改善を定量化する
2. **FT と RAG の相補性の検証**: FT + RAG が個々のシステムを超える相乗効果を持つかを検証する
3. **C0 → C3 の累積改善における各要素の寄与率の確定**: プロンプト改善・モデル変更・FT の寄与を精密に分離する

### 1.3 実験設計の革新点

従来の 3 システム比較（A: RAG、B: FT+改善プロンプト、C: FT+RAG）に加え、**System D（FT + C0 オリジナルプロンプト、RAG なし）** を追加した 4 システム比較を採用した。これにより、B と D の差分から「プロンプト改善の寄与」を、D と C0 ベースラインの差分から「FT の純粋効果」を分離できる実験設計とした。

### 3.1 Loss 推移

| Step | Train Loss | Eval Loss | 備考 |

| 初期 | — | — | — |
| Epoch 1 | 0.512 | 0.421 | 急速な初期収束 |

| Epoch 4 | 0.098 | 0.358 | Eval loss 微増（過学習の兆候） |
| Epoch 5 | **0.086** | 0.355 | Train loss 継続低下、eval loss 停滞 |

### 3.2 学習過程の評価

- **Best eval loss**: 0.355（Epoch 3）
- **Final train loss**: 0.086
- **Train/Eval gap**: 0.086 vs 0.355（4.1 倍）
- **判定**: Train loss が eval loss の 1/4 以下まで低下しており、**学習データへの過適合が発生**。ただし eval loss は Epoch 3 以降大きく悪化していないため、壊滅的な過学習ではない。

### 3.3 考察

Train loss 0.086 は学習データの形式・パターンをほぼ完全に記憶したことを意味する。しかし 59 件という少量データでは、地理的知識の一般化に必要なパターンの多様性が不足している。学習は「回答の形式」を獲得したが、「地理的知識」そのものは獲得していない可能性が高い。

## 5. 寄与分離分析

本実験の核心的分析である。System D の追加により、従来の 3 システム比較では不可能だった精密な寄与分離を実現した。

### 5.1 4 要素の寄与分解

| 要素 | 算出方法 | Composite | Reasoning | Evidence | Success% |
|------|----------|-----------|-----------|----------|----------|
| FT 純粋効果 | D - C0 baseline | **-1.0** | N/A | N/A | N/A |
| プロンプト改善効果 | B - D | **+16.7** | +1.81 | +1.03 | +38.5 |
| RAG 効果 (非 FT) | A - D | **+19.2** | +1.72 | +1.59 | +46.9 |
| RAG 効果 (FT) | C - B | **+1.6** | -0.08 | +1.03 | +8.5 |
| FT+RAG 相乗効果 | C - max(A,B,D) | **-0.9** | -0.08 | +0.47 | 0.0 |

### 5.2 寄与の構造的理解

```
C0 ベースライン:    52.2
                     │
                     ├─── FT 純粋効果: -1.0 ──→ D (FT-bare): 51.2
                     │                            │
                     │                            └── プロンプト改善: +16.7 ──→ B (FT+prompt): 67.9
                     │                                                           │
                     │                                                           └── RAG 追加: +1.6 ──→ C (FT+RAG): 69.5
                     │
                     └─── RAG + プロンプト: +18.2 ──→ A (RAG): 70.4
```

### 5.3 解釈

#### 発見 1: QLoRA FT の純粋効果はゼロ

D (51.2) ≈ C0 baseline (52.2)。59 件の QLoRA 学習はモデルの地理的知識を実質的に改善していない。train loss 0.086 への収束は学習データの表層パターン（回答形式）の暗記であり、地理的事実の汎化獲得ではない。

この結果は、QLoRA の限界というよりも **学習データ量の限界** を示唆する。59 件では、4 エリア × 16 サブカテゴリ × 5 レベルの組み合わせ空間（理論上 320 パターン）の 18.4% しかカバーできていない。

#### 発見 2: プロンプト改善が支配的な寄与要因

B - D = +16.7pt は、C0 → C2 の全改善量 (18.2pt) の **91.8%** に相当する。C1 改善プロンプトの指示（構造化回答、論理接続詞、具体的数値引用）が回答品質の大部分を決定している。

この知見は Step 1 (C0 → C1: +14.9pt) の結果と整合する。プロンプトエンジニアリングは、モデル変更 (+3.3pt) や FT (-1.0pt) と比較して桁違いの費用対効果を持つ。

#### 発見 3: FT+RAG の相乗効果は負

C (69.5) < A (70.4)。FT と RAG を組み合わせても、RAG 単体を下回る。Evidence score (+0.47) では微小な相乗効果が見られるが、composite 全体では干渉が発生している。

考えられるメカニズム：FT による回答パターンの固定化が、RAG が提供する動的なコンテキストの活用を阻害。特に multi_hop（A: 82.5 → C: 70.0）や competitor（A: 77.8 → C: 63.8）で顕著な劣化が見られる。

学習データに使用した 59 件と、それ以外の 71 件でスコアを比較し、FT による過学習の有無を検証した。

| System | FT data (59 件) | Non-FT (71 件) | Gap | 判定 |
|--------|-----------------|----------------|-----|------|
| A: RAG (C2) (参考) | 79.0 | 63.3 | **+15.6** | 参考値 |
| B: FT+prompt | 68.1 | 67.7 | **+0.5** | 過学習なし |
| C: FT+RAG | 75.3 | 64.7 | **+10.6** | 有意な過学習 |
| D: FT-bare | 50.2 | 52.0 | **-1.8** | 過学習なし |

### 7.2 判定基準

| Gap | 判定 |
|-----|------|
| <= 5pt | 過学習なし |
| 5-10pt | 軽度の過学習 |
| > 10pt | 有意な過学習 |

### 7.3 分析

注目すべきは **System A（FT なし）の gap が +15.6 で全システム中最大** であること。System A は QLoRA 学習を行っていないため、この gap は FT による過学習ではなく、**学習データ選定バイアス** に起因する。

学習データは `composite_score >= 70` の条件で選定されたため、もともと RAG システムが高スコアを記録した「解きやすい」問題が含まれている。この選定バイアスにより、FT data と Non-FT data の間に本質的な難易度差が存在する。

System C の gap (+10.6) も、この文脈では FT 固有の過学習というよりテストケースの特性差の影響が大きいと解釈すべきである。System B の gap (+0.5) がほぼゼロであることが、この仮説を支持する。

## 9. 考察

### 9.1 なぜ QLoRA FT は効果がなかったのか

本実験で FT の純粋効果がゼロであった原因を、以下の 3 つの仮説で考察する。

**仮説 1: 学習データ量の絶対的不足**

59 件の学習データは、4 エリア × 16 サブカテゴリ × 5 レベルの組み合わせ空間（320 パターン）の 18.4% しかカバーしていない。先行研究では、ドメイン固有の QLoRA で有意な効果を得るには最低 500-1000 件が推奨されている。本実験の 59 件はこの閾値を大きく下回る。

**仮説 2: 学習データの多様性不足**

学習データは C2 の高品質回答から自動選定されたため、すでに RAG + 改善プロンプトで「うまくいく」パターンに偏っている。FT が学習したのは「既に成功しているパターンの再現」であり、新たな能力の獲得ではない。

**仮説 3: 32B モデルの事前学習知識との干渉**

Qwen3-32B は膨大な事前学習知識を持つ。59 件の少量データによる LoRA 適応は、この既存知識と干渉し、特に高度な推論タスク（L5: multi_hop, sensitivity）で「知識の上書き」が悪影響を及ぼした可能性がある。

### 9.2 プロンプト改善の優位性の理由

プロンプト改善が +16.7pt もの効果を持つ理由は、本タスクの性質に起因する。地理的 POI 質問応答では：

1. **知識はモデル内部ではなく RAG コンテキストに存在する**: FT で知識を注入する必要がなく、プロンプトで「コンテキストの使い方」を指示するだけで十分
2. **回答品質は形式と構造で決まる**: reasoning_score や evidence_score は、推論過程の明示・根拠引用という「出力形式」に依存する。プロンプトで直接制御可能
3. **LLM の推論能力は十分**: 32B モデルは instruction following 能力が高く、プロンプトの指示を忠実に実行できる

### 9.3 FT+RAG の干渉メカニズム

FT+RAG（System C）が RAG 単体（System A）を下回る現象は、以下のメカニズムで説明可能：

- FT により回答パターンが学習データの形式に固定化される
- RAG が提供する動的なコンテキスト（検索結果）に対して、固定化されたパターンが柔軟に対応できない
- 特に学習データに存在しないタイプの質問（multi_hop、competitor 等）で顕著な劣化が発生

ただし、L3 Constraint（85.5 > 84.8）や L4 Decision（72.9 > 69.1）では C が A を上回っており、構造化された制約処理タスクでは FT+RAG の相補性が機能する局面もある。

## 10. 結論

### 10.1 主要結論

1. **QLoRA FT の純粋効果はゼロ**: 59 件の学習データによる QLoRA は、地理的 POI 質問応答の品質を改善しない（D: 51.2 vs C0: 52.2 = -1.0pt）。学習データの量的・質的不足が主因

2. **プロンプト改善が支配的な改善要因**: C0 → C2 の全改善量 18.2pt のうち、プロンプト改善が 81.9%（+14.9pt）を占める。費用対効果で最も優れた品質改善手法

3. **FT+RAG の相乗効果は負**: 全体では FT が RAG の効果を阻害（-0.9pt）するが、制約処理タスク（L3: +0.7pt、L4: +3.8pt）では限定的な相補性を確認

4. **C3 目標は未達**: composite 69.5（目標 75+）、reasoning 3.08（目標 3.5+）。Evidence score のみ 4.32 で目標達成

5. **過学習分析において選定バイアスの影響を検出**: System A（FT なし）の FT-data/Non-FT gap が +15.6 で最大であり、学習データ選定の非ランダム性がスコア比較を歪めている

### 10.2 Phase 9-C 総括

| Step | 手法 | Composite 改善 | 累積 | 判定 |
|------|------|---------------|------|------|
| C0 | ベースライン | — | 52.2 | — |
| Step 1 | プロンプト改善 | **+14.9** | 67.1 | 最大効果 |
| Step 2 | モデル変更 (32B) | +3.3 | 70.4 | 有効 |
| Step 3 | QLoRA FT | **-0.9** | 69.5 | 無効（採用せず） |

**Phase 9-C の最終到達点は C2（Step 2）の 70.4pt**。Step 3 の QLoRA FT は採用しない。

## 11. 今後の展望

### 11.1 短期施策（C3 目標 75+ 達成に向けて）

本実験の知見から、以下の施策が有望である：

1. **プロンプトの更なる改善（C1 → C2 プロンプト）**: Step 1 で +14.9pt の実績がある。L4 Decision/L5 Advanced の弱点に特化したプロンプト改良（推論チェーン明示の強化、不確実性表現の緻密化）により +3-5pt の追加改善を見込む

2. **RAG 検索精度の向上**: 現在の ChromaDB + multilingual-e5-base から、より高精度な埋め込みモデル（multilingual-e5-large 等）への移行、または reranker の導入による検索品質改善

3. **生成パラメータの最適化**: temperature 0.7 → 0.3-0.5 への調整による hedging 軽減、enable_thinking=True による推論品質向上（時間とのトレードオフ）

### 11.2 中期施策（FT の再挑戦条件）

QLoRA FT を再び試みる場合の条件：

| 項目 | 今回の実験 | 推奨条件 |
|------|-----------|---------|
| 学習データ量 | 59 件 | **500 件以上** |
| データ多様性 | C2 高スコアのみ | **全レベル・全サブカテゴリを均等にカバー** |
| データ品質管理 | 自動選定 | **人手によるキュレーション + 品質検証** |
| 評価設計 | 学習データと評価データが重複 | **完全に独立した評価セットを確保** |

### 11.3 長期展望

#### 一連の実験から得られた知見の応用

Phase 9-C の 3 ステップ実験を通じて得られた知見は、地理的 POI 質問応答に限らず、**RAG ベースの専門ドメイン QA システム全般** に応用可能である：

1. **プロンプトファースト原則**: ドメイン固有 QA においては、FT やモデル変更の前にプロンプト改善を徹底すべきである。本実験では、プロンプト改善が全改善量の 81.9% を占め、FT はゼロ効果であった。この「プロンプト → モデルスケール → FT」の優先順位は、他の専門ドメイン（法律、医療、金融等）の RAG システムにも一般化できる可能性が高い

2. **4 システム比較による寄与分離手法**: System D（FT + 旧プロンプト）を追加する実験設計は、FT の効果をプロンプト効果と分離するための汎用的手法として提案できる。FT 実験の報告においてこのコントロール群を設けることで、FT の真の効果を過大評価するリスクを回避できる

3. **少量データ FT の限界閾値**: 59 件（パターン空間の 18.4%）ではゼロ効果であった。ドメイン固有 QA における FT の効果発現には、タスク空間の少なくとも 50% 以上をカバーする学習データが必要と推測される

4. **RAG と FT の関係性**: RAG が外部知識を提供するシステムでは、FT による内部知識の注入は冗長または干渉的になりうる。FT の価値は「知識の注入」ではなく「出力形式の最適化」にあり、それはプロンプトで代替可能であった

#### 全国展開への示唆

Phase 10 での PostGIS/Supabase による全国展開（500 万 POI 規模）に向けて、本実験は以下の設計指針を提供する：

- **RAG + 改善プロンプトの組み合わせが最も堅牢**: エリア・難易度を問わず安定した品質を提供
- **FT は全国規模の多様なデータが揃ってから再検討**: 各エリアの特性を反映した大規模学習データ（1000 件以上）が確保できた段階で再評価
- **動的な基準点解決とプロンプトの汎化**: 渋谷固有のハードコーディングを排し、ジオコーディング API と組み合わせた場所非依存のプロンプト設計が必要
